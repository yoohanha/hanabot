# [5-2] 세 가지 방식 비교 결과

## 테스트 개요
- 테스트 질문: 5개
- A 방식: 한 번에 답 (6과정 메뉴 11번 방식)
- B 방식: 계획 + 실행
- C 방식: 계획 + 실행 + 검토

## 합계

| 방식 | 맞힌 수 | 정확도 |
|------|--------|--------|
| A (직접 답) | 5/5 | 100% |
| B (계획+실행) | 5/5 | 100% |
| C (계획+실행+검토) | 5/5 | 100% |

## 분석

### 정답 기준
- Q1: 지각 3회는 결석 1회로 처리
- Q2: 300,000원
- Q3: 450,000원
- Q4: 10%
- Q5: 4시간

### 성능 비교
- **정확도**: 모든 방식이 100% 정답 (5/5)
- **속도**: 
  - A (직접 답): 평균 1.16초
  - B (계획+실행): 평균 2.20초  
  - C (계획+실행+검토): 평균 3.34초
- **신뢰성**: 계획과 검토가 답의 정확도를 높이지는 않지만, 과정의 투명성을 제공

## 결론

✅ **세 가지 방식 모두 동일한 정확도 달성**

- **A 방식**: 가장 빠르고 간단 (1.16초)
- **B 방식**: 중간 속도, 계획 기반 체계적 답변 (2.20초)
- **C 방식**: 가장 느리지만 검토 단계로 신뢰성 강화 (3.34초)

**추천**: 실시간 대화형 에이전트에는 **A 방식** 추천, 중요한 의사결정이 필요한 경우 **B 또는 C 방식** 추천
