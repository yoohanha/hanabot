  scp -i hanabot-key.pem ubuntu@<공인_IP>:/home/ubuntu/hanabot/web/data/* ./local-backup/

### 2. 서비스 정리
- [ ] 하나봇 웹 서버 중지:
  ```bash
  ssh -i hanabot-key.pem ubuntu@<공인_IP>
  docker-compose -f docker-compose.aws.yml down
  ```
- [ ] Ollama 모델 캐시 (선택):
  - 재사용 예정 → 보관 (다시 다운로드 불필요)
  - 재사용 미정 → 디스크 용량 절감 고려

### 3. EC2 인스턴스 관리

#### 옵션 A: 임시 중지 (권장 - 비용 절감)
- [ ] AWS 콘솔: **EC2** → **인스턴스** → 선택 → **인스턴스 상태** → **중지**
- [ ] 비용: EBS 스토리지 (약 KRW 500/월) + 고정 IP (약 KRW 5,000/월)
- [ ] 재시작: 1-2분 (모델 캐시 사용하므로 빠름)
- [ ] 체크포인트: 유지됨

#### 옵션 B: 완전 삭제 (비용 0)
- [ ] AWS 콘솔: **EC2** → **인스턴스** → 선택 → **인스턴스 상태** → **종료**
- [ ] 경고: **데이터 모두 삭제됨** (백업 필수!)
- [ ] 재시작: 새 인스턴스 생성 (20-30분 소요)

### 4. 디스크 용량 정리 (선택사항)

#### EBS 볼륨 축소
- [ ] 100GB → 필요한 크기로 조정 (AWS Console)
- [ ] 비용 절감: 약 KRW 10/GB/월
- [ ] 주의: 운영 중 축소 불가 (인스턴스 중지 필요)

#### 모델 삭제 (저장 공간 확보)
```bash
# [5-7] Ollama 모델 삭제 (약 50GB 절감)
ollama rm llama3.1
ollama rm bge-m3

# [5-7] Docker 이미지 삭제 (약 2GB 절감)
docker rmi hanabot:5-6
```

### 5. 고정 IP 관리

#### 고정 IP 사용 시
- [ ] AWS 콘솔: **탄력적 IP** → 사용하지 않는 IP 확인
- [ ] **연결 해제** 또는 **삭제**
- [ ] 비용: 고정 IP 미사용: 약 KRW 5,000/월

#### 동적 IP 사용 (권장)
- [ ] 고정 IP 없음 → 비용 절감
- [ ] 재시작 시 IP 변경 (보안 그룹 규칙 수정 필요)

### 6. 예산 알림 설정

#### AWS Billing 알림
- [ ] AWS 콘솔: **빌링** → **예산**
- [ ] **예산 생성**:
  - 월간 한도: KRW 500,000 (약 $400)
  - 알림: 80% 도달 시 이메일 받기
  - 초과 시 자동 종료 설정 (선택)

#### 월별 비용 추적
- [ ] AWS 콘솔: **Cost Explorer** 확인
- [ ] g4dn.xlarge 한 달 24시간 운영: 약 KRW 486,720

### 7. 보안 정리

## ❓ 자주 묻는 질문

### Q: 비용은 언제 청구되나?
- A: AWS는 매월 청구 (보통 월말)
- 예산 초과 시에도 계속 청구됨
- 자동 중지 설정 권장

### Q: 중지 중에도 비용이 나오나?
- A: 예
  - EBS 스토리지: 계속 청구 (약 KRW 500/월)
  - 고정 IP: 사용 중이면 계속 청구 (약 KRW 5,000/월)

### Q: 모델을 다시 다운받아야 하나?
- A: 아니요 (EBS 스토리지에 캐시됨)
- 중지 → 재시작: 모델 재다운로드 불필요
- 완전 삭제: 모델 재다운로드 필요

### Q: 사용 중 비용을 줄일 수 있나?
- A: 예
  - 사용하지 않을 때는 EC2 중지
  - 더 작은 인스턴스 타입 고려 (CPU만 필요 시 `t3.medium`)
  - 고정 IP 제거
