# [5-7] AWS 보안 그룹 규칙

## 🔐 EC2 보안 그룹: `hanabot-sg`

### 인바운드 규칙 (Inbound)

| 규칙 | 프로토콜 | 포트 | 소스 | 용도 | 비고 |
|------|---------|------|------|------|------|
| SSH | TCP | 22 | **내 IP/32** | EC2 원격 접속 | ⚠️ 내 IP만! |
| HTTP | TCP | 8080 | **내 IP/32** | 하나봇 웹 접속 | ⚠️ 내 IP만! |
| ~~HTTP~~ | ~~TCP~~ | ~~11434~~ | ~~차단~~ | ~~Ollama~~ | ✅ 내부 전용 (외부 차단) |

### 아웃바운드 규칙 (Outbound)

| 규칙 | 프로토콜 | 포트 | 대상 |
|------|---------|------|------|
| 모든 트래픽 | 모든 | 모든 | 0.0.0.0/0 |

## 🔧 설정 방법 (AWS 콘솔)

### 1. 보안 그룹 생성
1. **EC2 대시보드** → **보안 그룹** → **보안 그룹 생성**
2. **이름**: `hanabot-sg`
3. **설명**: 하나봇 GPU 서버 보안 그룹
4. **VPC**: 기본값 (default-vpc)

### 2. 인바운드 규칙 추가

#### SSH (22번 포트)
- **유형**: SSH
- **프로토콜**: TCP
- **포트**: 22
- **소스**: `내_IP/32` (또는 `MY_IP/32`)
  - IP 확인: https://whatismyipaddress.com
  - 예: `203.0.113.42/32` (실제 IP로 교체)
- **설명**: SSH 원격 접속

#### HTTP (8080 포트 - 하나봇 웹)
- **유형**: 사용자 지정 TCP
- **프로토콜**: TCP
- **포트**: 8080
- **소스**: `내_IP/32`
- **설명**: 하나봇 웹 인터페이스

#### Ollama (11434 포트 - 차단)
- **추가하지 않음** ✅
- 의도: Ollama는 웹 서버 경유로만 사용
- 이유: 보안 (외부에서 직접 모델 접근 불가)

### 3. 아웃바운드 규칙 (기본값 유지)
- **모든 트래픽** → **0.0.0.0/0** (모든 아웃바운드 허용)

## ⚠️ 주의사항

### 개발 중
- **내 IP만** 허용 (보안)
- 같은 네트워크의 팀원? → 팀원 IP 추가

### 프로덕션 배포
1. **IP 화이트리스트**: 필요한 IP만
2. **로드밸런서**: CloudFront 또는 ALB 앞에 배치
3. **HTTPS**: SSL/TLS 인증서 추가
4. **API 키**: 모든 엔드포인트에 인증 추가

### IP 변경 시
- 집/카페/사무실마다 IP 다름
- 보안 그룹 규칙 수동 업데이트 필요
- 또는 임시로 `0.0.0.0/0` 사용 (테스트만!)

