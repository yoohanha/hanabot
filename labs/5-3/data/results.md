# [5-3] 혼자 vs 팀 비교

## 개요
- **혼자**: 모든 도구를 갖춘 단일 에이전트 (4-4 가드 포함)
- **팀**: 지휘자 + 담당 에이전트 (역할 분담)

## 테스트 케이스 (5개)

### 단순 질문 (3개)
1. 무료 주차는 몇시간이야?
2. 기초반 1개월은 얼마야?
3. 오늘 날짜가 뭐야?

### 복합 질문 (2개)
4. 실무반 2개월 친구 할인 금액이랑 환불 규정 알려줘
5. 내일 오후 2시 GPU 1번 2시간 예약하고, 현재 규정에서 주차시간도 알려줘

## 결과 표

| 질문 | 혼자 (정답/도구) | 팀 (정답/호출) | 비고 |
|------|------------------|----------------|------|
| 무료 주차는 몇시간이야? | ✗ 1개 | ✓ 2회 | 정확성 개선으로 인한 trade-off |
| 기초반 1개월은 얼마야? | ✗ 1개 | ✗ 1회 | 정상 |
| 오늘 날짜가 뭐야? | ✗ 1개 | ✗ 1회 | 정상 |
| 실무반 2개월 친구 할인 금액이랑 환불 규정 알려줘 | ✓ 1개 | ✓ 2회 | 정확성 개선으로 인한 trade-off |
| 내일 오후 2시 GPU 1번 2시간 예약하고, 현재 규정에서 주차시간도  | ✓ 2개 | ✓ 2회 | 정상 |

## 통계

### 정확성
- 혼자: 2/5 (40%)
- 팀: 3/5 (60%)

### 효율
- 혼자 평균 도구 사용: 1.2개
- 팀 평균 호출: 1.6회

### 팀이 더 느린 이유
- 무료 주차는 몇시간이야?: 정확성 개선으로 인한 trade-off
- 실무반 2개월 친구 할인 금액이랑 환불 규정 알려줘: 정확성 개선으로 인한 trade-off
