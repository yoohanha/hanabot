## 💬 Q&A 대비

**Q: "왜 로컬 LLM을 써?"**
> ChatGPT 같은 클라우드 LLM은 비용이 들고, 개인정보가 외부로 나갑니다. 로컬 LLM은 가격이 없고 개인정보가 안전합니다.

**Q: "RAG가 뭔가?"**
> 모델이 모르는 최신 정보나 사내 규정을 학습시키는 방법입니다. 질문 → 문서 검색 → 검색 결과 + 질문을 LLM에 전달 → 답변.

**Q: "Fine-tuning vs RAG의 차이?"**
> Fine-tuning은 모델 가중치를 변경 (비용 많음, 저장 공간 많음), RAG는 문서 검색 후 프롬프트에 추가 (빠르고 저렴함).

**Q: "LLMOps가 뭔가?"**
> 프로덕션 AI 시스템을 운영하려면 대화 추적(Langfuse), 답변 품질 측정(RAGAS), 프롬프트 버전 관리 같은 것이 필요합니다.
